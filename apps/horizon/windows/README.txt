PRISMO FIELD KIT / HORIZON - WINDOWS x64

1. Extract this entire ZIP into a folder on your Windows PC.
2. Double-click PrismoFieldKit.exe. Keep the accompanying _internal folder.
3. Your browser opens http://127.0.0.1:8765.
4. Keep the console window open while planning. Ctrl+C stops the app.

No Docker, Python, Node or administrator installation is required.
Data is saved separately in %LOCALAPPDATA%\PrismoFieldKit\Horizon.
Updating or moving this program folder does not remove your projects.
Back up the entire data folder while the app is stopped.

The Prismo Field Kit link opens equipment, setup, checks and records.
Prepare terrain and any additional datum grids before going offline.
The bundled example is synthetic. Real radio power/thresholds must be supplied.

This executable is unsigned. Windows may display a reputation warning.
Use only the package and SHA256 checksums from the Field Kit repository.
It is not the recovered Windows manufacturing tester and does not add physical
configuration writes. Android's native transport limitations remain unchanged.

Optional command-line settings:
  PrismoFieldKit.exe --port 8767
  PrismoFieldKit.exe --data "D:\Field data\Horizon"
  PrismoFieldKit.exe --no-browser

If the default port is occupied by a different app, use another --port.
Open Horizon on the PC running it; this loopback address is not a phone link.
